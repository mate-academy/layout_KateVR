# KatVR

## 🎮 About the Project
Created a futuristic landing page design focused on showcasing next-generation technology and devices. The page features sleek and modern aesthetics with smooth interactions to highlight the cutting-edge nature of the brand.

## 🚀 Tech Stack
- **HTML (BEM)** – Structuring the page layout and components in a maintainable way
- **CSS (SCSS)** – Styling the page with a scalable, modular approach
- **JS** – Implementing dynamic behavior and interactivity on the page
- **Adaptive** – Making the page fully responsive across various devices

## 🛠️ Tools & Dependencies
- **ESLint** – Code linting for consistent coding standards  
- **Jest** – For unit testing and ensuring code quality  
- **Prettier** – Automatically formatting code for better readability  
- **Parcel** – Efficient bundling and development workflow
